# 胜任力建模 Skill

> 通过交互式配置向导，基于候选人画像生成三层结构胜任力模型报告

## 功能特性

- **三层胜任力建模**：冰山上（可观测行为）→ 冰山中（可发展能力）→ 冰山下（不易改变特质）
- **谱系追问法**：StopAndThink 框架，从抽象描述逐层追问到具体行为证据
- **动态可视化**：四类合规图表（旭日图 / 矩形树图 / 散点图 / 能力树），禁止雷达图
- **校验引擎**：内部一致性检测 + 校招/社招污染检测 + 可视化有效性检查
- **多场景适配**：校招 / 社招 / 晋升评估 / 团队盘点

## 快速使用

在工作流入口中引用：

```
Use the talent-model skill. Target role: [岗位名称], Level: [校招/实习/资深/管理], Scenario: [招聘/面试/晋升], Companies: [公司A, 公司B, ...]
```

## 方法论框架

### 三层冰山模型

| 层级 | 名称 | 特征 |
|------|------|------|
| Layer 1 | 可观测行为 | 可直接观察的工作行为和产出 |
| Layer 2 | 可发展能力 | 通过培养可提升的能力 |
| Layer 3 | 不易改变特质 | 长期稳定的人格特质，难以短期改变 |

### 核心原则

1. **数据驱动而非直觉驱动** — 胜任力来自候选人实际行为证据，不来自推断
2. **区分可观测与不可观测** — Layer 1 必须可直接观察，Layer 3 须追问验证
3. **拒绝先验框架** — 不使用外部评估框架（如 McClelland、SHL）的既有标准
4. **图表克制** — 只使用能直接反映数据关系的图表类型

### 禁止事项

- 🚫 雷达图（大模型倾向使用，但会产生量化幻觉）
- 🚫 校招/社招标准混用
- 🚫 直接套用外部预设胜任力模型
- 🚫 将推断的"性格特质"作为 Layer 1 行为描述
