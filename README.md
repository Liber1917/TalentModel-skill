# Talent Model Skill

🎯 **岗位胜任力建模工具** — 通过交互式配置向导，基于候选人画像而非技能清单，生成三层结构（核心维度→可观察行为→角色证据）的胜任力模型报告。

---

## 核心特点

- **交互式配置向导** — 10步引导式配置，带智能提示和意图识别
- **MECE 结构建模** — 6维胜任力框架，避免技能树陷阱
- **官网验证** — 基于真实招聘页面交叉验证
- **HTML 可视化报告** — 4种图表（旭日图、矩形树图、散点图、能力树）

---

## 使用方法

### 1. 启动 Skill

```bash
# 在 agent 中使用
@talent-model
```

或对话中直接说：
> "帮我做一个 AI Infra 的胜任力模型"

或把下面的内容复制给Chatbox对话：
```
请为目标岗位构建一套“候选人人才画像导向”的胜任力模型，而不是技能清单。

要求：
1. 先建模“人”，再映射“可观察行为”，最后给出“岗位/行业场景证据”；
2. 一级维度请遵循 MECE，避免把工具、平台、技术栈直接当成核心维度；
3. 请结合官网/官方招聘页、官方校招/实习页或官方 careers 页面做交叉检验；
4. 如果初始模型和官方来源差异较大，请按以下顺序修正：
   wording → evidence → boundary → core dimensions
   也就是先改表述，再补证据层，再调维度边界，最后才考虑调整一级维度；
5. 请输出：
   - 一句话人才画像总结
   - 一级胜任力维度
   - 每个维度的定义
   - 可观察行为
   - 岗位场景证据
   - 官方来源检验结论
   - 适用边界与注意事项
   - 【仅当输出HTML时】批判性分析（Section 00）：对该MECE建模思路进行"扬弃"分析，明确保留与修正的内容
   - 【仅当输出HTML时】官网验证链接（Section 05），每个链接必须包含"检验点"说明，标注该链接用于检验模型的哪个维度或特质
6. 如果我没有提供完整参数，请不要直接假设；请通过对话交互，逐步帮助我补齐岗位、层级、用途、行业语境、验证公司、输出格式等必要信息；
7. 如果我要求输出 HTML，请在完成模型与检验后，再生成完整单文件 HTML（含4种图表 + 官网验证链接），默认不要给出量化权重。链接选择优先级：官方校招/实习入口 > 官方招聘主页 > 具体岗位页面（上限参照）；
7.5 【可选】是否添加自测矩阵（三水位：🌱起步/⚡达标/🔥突出）— 适用于候选人有自测需求的场景；
7.6 【可选】图表渲染方式：完全离线（内嵌echarts.min.js）vs 外部CDN — 抛给用户选择；
8. HTML报告应包含人才分型象限（散点图 + 行为锚点表格），帮助识别潜力型/达标型/突出型/平台型人才。
```

### 2. HTML 报告使用方式

当选择 **HTML报告** 输出格式时，会生成两个文件：

| 文件 | 说明 |
|------|------|
| `{岗位名称}_胜任力模型.html` | 主报告文件 |
| `echarts.min.js` | ECharts 图表库（必须放在同一目录） |

**使用步骤：**

1. **确保两个文件在同一目录**
   ```
   工作目录/
   ├── 嵌入式软件工程师_胜任力模型.html
   └── echarts.min.js          ← 必须存在
   ```

2. **用浏览器打开 HTML 文件**
   - 双击 HTML 文件即可在浏览器中查看
   - 支持 Chrome、Edge、Firefox、Safari 等现代浏览器

3. **离线使用**
   - 报告完全离线可用，无需网络连接
   - 所有图表通过本地 `echarts.min.js` 渲染

**⚠️ 注意：**
- 如果图表无法显示，请检查 `echarts.min.js` 是否与 HTML 文件在同一目录
- 不要删除或移动 `echarts.min.js` 文件
- 如需分享报告，请同时分享 HTML 文件和 `echarts.min.js`

### 3. 配置参数

| 参数 | 说明 | 示例 |
|------|------|------|
| `ROLE_NAME` | 目标岗位名称 | AI Infra工程师 |
| `TALENT_LEVEL` | 人才级别 | 校招/实习/资深专家/管理者 |
| `USE_CASE` | 使用场景 | 招聘筛选/面试设计/晋升评估 |
| `VALIDATION_COMPANIES` | 验证公司列表 | OpenAI, NVIDIA, ByteDance... |
| `OUTPUT_FORMAT` | 输出格式 | html / markdown |

## 核心原则

> **胜任力模型不是整理后的职位描述。**
> **它是对"组织真正想识别什么样的人"的结构化判断。**
> **先建模人，再映射行为，最后验证证据。**
