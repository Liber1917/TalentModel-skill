结论

  • CDN ECharts 视觉质量更高：配色精准、层级清晰、hover 交互自然
  • CSS 方案的扇区颜色只能粗略近似，无法达到 ECharts 的平滑渐变层次
  • CDN ECharts 使用统一 `value: 1` 占位，从根本上规避量化幻觉
  • CDN 加载后浏览器自动缓存，后续完全离线可用
  • CSS 方案适合：超简版演示、无法联网的纯本地报告
  • CSS 方案不适合：需要精确配色和层级区分的正式人才报告
